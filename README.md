# The Pasta King – demo website

Statische demo website in de huisstijl van The Pasta King (krijtbord, rode balken, Montserrat + script-accent).

- `index.html` – volledige site (menu met klein/groot-schakelaar, bak-samensteller met winkelmand, over ons, socials)
- `assets/` – logo (origineel + transparante versie) en de originele menukaart

Openen: dubbelklik `index.html`, of `python3 -m http.server` en ga naar http://localhost:8000.

Let op: dit is een demo. Afrekenen plaatst geen echte bestelling; adres en openingstijden zijn nog niet ingevuld.
